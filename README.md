# 성적분석 보고서 도우미

화성 반월고등학교 교원을 위한 정기시험 성적분석 보고서 작성 도구입니다.
나이스(NEIS)의 학급 평균, 문항 정답률, 문항정보표, 급간 분포를 넣으면 A4 2쪽 성적분석 보고서와 출제·수업 개선 조언이 자동으로 작성됩니다.

## 주요 기능
- 8단계 입력 안내와 직접 해보는 따라가기 튜토리얼
- 나이스 표 붙여넣기 / 엑셀 파일 끌어다 놓기 자동 인식
- 평균·문항·급간·성취도 분석과 규칙 기반 개선 조언
- 지난 시험과 내용요소별 비교
- PDF 저장, 인쇄
- (선택) 개인 Gemini API 키로 AI 맞춤 조언 받기

## 개인정보와 보안
- 서버 없이 브라우저 안에서만 작동하며, 넣은 자료는 사용하는 컴퓨터의 브라우저에만 저장됩니다.
- 학생 이름·학번 등 개인정보는 다루지 않습니다.
- AI 맞춤 조언을 직접 요청할 때만 요약 통계가 Google Gemini로 전송됩니다.
